```release-note:bug
data-source/k0rdent_vpc: Fix a read of a VPC released by an interrupted destroy failing the next plan, with "Missing Configuration for Required Attribute" when `id` comes from the owner's `vpc`, or "No such VPC" when the data source has `depends_on` for the owner. The read now returns `id`, `region`, `project`, `self_link` and an empty `security_groups` list, with a warning that names `terraform destroy -refresh=false` for any expression that can't use those values. A null `state` marks this read. A literal `id` without that dependency can fail with "No such VPC", and `terraform destroy -refresh=false` finishes the teardown there too. The "No such VPC" error now names that command as the way out. A precondition on `backend`, like the one in earlier copies of the full walkthrough, fails on this read. Add `state == null ||` to it, or finish with `terraform destroy -refresh=false`
```
