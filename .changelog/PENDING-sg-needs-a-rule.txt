```release-note:breaking-change
resource/k0rdent_security_group: A plan to create a group with no `ingress` and no `egress` block, or to change a group that has none, fails with "A security group needs at least one rule". API 1.4 refuses either request with HTTP 422. API 1.3 accepts the request, and the fabric can then leave the group `failed`. Add an `ingress` or `egress` block. A group already in state with no rules and nothing to change plans with a warning, and `terraform destroy` deletes it. With a configured `id`, a tainted replacement of an unchanged group with no rules warns at plan and fails in `Create` at apply. Plain `terraform destroy`, `terraform destroy -refresh=false`, and a saved destroy plan all delete it. A generated-id tainted replacement still needs `terraform destroy -refresh=false`
```
