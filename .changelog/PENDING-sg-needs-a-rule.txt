```release-note:breaking-change
resource/k0rdent_security_group: A plan to create a group with no `ingress` and no `egress` block, or to change a group that has none, fails with "A security group needs at least one rule". API 1.4 refuses either request with HTTP 422. API 1.3 accepts the request, and the fabric can then leave the group `failed`. Add an `ingress` or `egress` block. A group already in state with no rules and nothing to change plans with a warning, and `terraform destroy` deletes it. A tainted replacement with no rules in configuration is refused at plan for either a configured or generated `id` because the configuration makes the replacement's create invalid. Add an `ingress` or `egress` block, or run `terraform destroy -refresh=false` to delete the group
```
